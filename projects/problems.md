# 有限自动机思考题集

## 2.1
title: 设计 DFA——不包含子串 011 的 0/1 串
question: 设计一个 DFA，识别所有不包含子串 011 的 0/1 串。请描述你的设计思路：需要哪些状态？状态之间的转换关系是怎样的？哪些是终态？
reference:
  - 设计思路（自动机运转观点）：从初态开始，读入符号 0/1，会进行状态迁移，对应不同的符号串集合，循此创建边和更多的状态。
  - 关键是创建的边指向新的状态，还是指向已有状态：回到“状态对应符号串集合”，当前状态对应符号串集合，沿着边进行状态迁移，相当于将边上符号拼接到当前符号串末尾，对扩展后的符号串集合，判断其含义是与某个已有状态一致，还是都不一致，从而决定应指向已有状态还是创建新的状态。
  - 对于本题，符号串集合表示的含义就是“构成 011 已经到了什么程度”（或者说，符号串将不被接受的“危险程度”）——一点都还没形成、已形成 0、已形成 01、已形成 011。注意，新符号拼接并不总是沿着四种含义直线前进，有些符号拼接会“破坏”已形成部分 011 结构（例如 01 后紧接着出现 0），回到危险更低的状态——意味着边指向已有状态。
  - 显然，状态是否是终态，也由符号串集合表示的“危险程度”决定。
  - 注意：“出现 011”对应死状态，虽然是否显式给出这个状态及其边都不影响 DFA 接受的符号串集合，但出于更好地理解有限自动机，要求学生给出完整的包含此状态的 DFA。

## 2.2
title: 设计 DFA——偶数个 0、偶数个 1 的 0/1 串
question: 设计一个 DFA，识别所有包含偶数个 0 且包含偶数个 1 的 0/1 串（空串 ε 合法）。请描述你的设计思路和状态转换关系。
reference:
  - 设计思路（状态对应符号串集合观点）：状态对应符号串集合，且一个完整的 DFA 的所有状态能匹配字母表上所有符号串。那么可以根据题意，将符号串全集划分为几个子集，分别对应 DFA 的各个状态，然后再构造状态之间的边。
  - 本题关心的是 0 和 1 的个数的奇偶性，可据此将全体 0/1 串划分为几个子集。
  - 0 边和 1 边分别表示在当前符号串末尾拼接了一个 0 或 1，可据此在对应符号串集合（状态）间连接边。
  - 偶数个 0、偶数个 1 对应的状态为终态。

## 2.3
title: 狼、羊、白菜问题的有限自动机模型
question: 农夫要带狼、羊、白菜过河，船只能容纳农夫和一样东西，请思考用 DFA 求解此问题的思路，回答以下问题：1）状态应表示什么？2）边应表示什么？3）初态和终态分别是什么？4）渡河方案对应 DFA 中的什么？
reference:
  - 农夫、狼、羊、白菜当前的位置就能准确表达当前状态，所有可能的位置就是状态数。
  - 什么会导致农夫、狼、羊、白菜当前的位置发生变化？这就是边代表的含义。
  - 初态和终态就是农夫、狼、羊、白菜的初始位置和结束位置。
  - 渡河方案就是从初始位置变化为渡河之后位置的方法，而位置对应状态，因此渡河方案就是状态变化的过程。
